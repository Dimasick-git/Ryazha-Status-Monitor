# Ryazha-Status-Monitor

**Ryazha-Status-Monitor** — русскоязычный оверлей мониторинга Nintendo Switch для экосистемы Ряженки. Проект собран на `libryazhahand`; его интерфейс, компактные метки и настройки рассчитаны на использование на экране консоли без переполнения текста.

| Возможность | Реализация |
|---|---|
| Язык интерфейса | Русский включён по умолчанию. Компактные метки: `ЦП`, `ГП`, `ОЗ`, `СЧ`, `ПП`, `АК`, `Т`, `ВР`. |
| Режимы | Полный, Мини, Микро, FPS-график, FPS + Гц и Разрешение. |
| FPS + Гц | Показывает FPS игры и фактическую частоту обновления экрана; вывод герц можно отключить в настройках режима. |
| Перемещение | Компактные режимы перетаскиваются касанием с удержанием; положение сохраняется. Удержание `+` включает перемещение стиком. |
| Тема | Активная тема `libryazhahand` применяется **только** к режиму «Полный». Остальные режимы сохраняют собственные палитры. |
| EMA-сглаживание | Независимые переключатели для FPS, частот, загрузок, температур и питания. По умолчанию выключено. |

## Установка

Скачайте `Ryazha-Status-Monitor.zip` из релиза и распакуйте его в **корень SD-карты**. Архив уже содержит нужную структуру папок:

```text
switch/.overlays/Ryazha-Status-Monitor.ovl
config/status-monitor/config.ini
config/status-monitor/lang/ru.json
config/ryazhahand/config.ini
```

После первой установки откройте меню оверлеев и выберите **Ряжа-Монитор**. Нажмите `A`, чтобы открыть режим; нажмите `+` на выбранном режиме, чтобы перейти к его настройкам. В настройках используются кнопки `A` для выбора и `B` для возврата.

## Режимы

| Режим | Назначение |
|---|---|
| **Полный** | Подробные частоты, нагрузки, температуры, питание, FPS, разрешение и чтение с SD. Это единственный режим, который использует активную тему Ряженки. |
| **Мини** | Компактная настраиваемая строка показателей для постоянного отображения. |
| **Микро** | Ещё более компактный вариант мониторинга. |
| **FPS-график** | График FPS с фактической шкалой частоты обновления экрана. |
| **FPS + Гц** | Крупный показатель FPS и текущих герц экрана. |
| **Разрешение** | Отображение разрешения рендера и viewport игры. |

## EMA-сглаживание

В меню **Настройки → EMA-сглаживание** доступны отдельные параметры:

| Параметр | Что сглаживается |
|---|---|
| **EMA: FPS** | Изменения FPS игры. |
| **EMA: частоты** | Целевые и фактические частоты ЦП, ГП и ОЗ. |
| **EMA: загрузка** | Загрузка ГП и ОЗ, включая пропускную способность памяти. |
| **EMA: температура** | Датчики СЧ, ПП, корпуса и компонентов. |
| **EMA: питание** | Ток, напряжение и потребляемая мощность аккумулятора. |

EMA не меняет реальные параметры консоли: она влияет только на визуальное отображение показателей. При выключении любого параметра его данные сразу возвращаются к исходным значениям.

## Сборка

Для сборки необходимы devkitPro, `libnx` и рекурсивно инициализированные зависимости:

```bash
git submodule update --init --recursive
make -j$(nproc)
make dist
```

Собранный оверлей появится как `Ryazha-Status-Monitor.ovl`, а готовая структура установки — в каталоге `out/`.
