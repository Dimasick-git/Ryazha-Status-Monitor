**Ryazha-Status-Monitor** — настраиваемый оверлей мониторинга Nintendo Switch для экосистемы Ряженки. Версия 1.5.5 получила полностью обновлённый Full-режим, плавное отображение телеметрии и отдельные виджеты, которые можно закреплять поверх игры.

## Возможности

| Возможность | Реализация |
|---|---|
| **Full 60 Гц** | Полный режим перерисовывается с частотой 60 Гц по умолчанию; частота опроса датчиков настраивается отдельно. |
| **Плавающие виджеты** | Карточки ЦПУ, ГПУ, ОЗУ, игры, температур и системы можно закрепить и свободно перемещать по всему экрану. |
| **Масштабирование** | Размер закреплённого виджета меняется щипком в диапазоне 60–225%; позиция и масштаб сохраняются отдельно для каждой карточки. |
| **Режим без панели** | `−` скрывает основную панель Full, но оставляет закреплённые виджеты поверх игры. Повторное нажатие возвращает панель. |
| **EMA-сглаживание** | Независимое сглаживание FPS, частот, загрузок, температур и питания. Фильтрация влияет только на отображение. |
| **Безопасные температуры** | Некорректные и невозможные значения датчиков отбрасываются до отображения и до попадания в EMA. |
| **Локализация** | Язык берётся из настроек `libryazhahand`. В комплект входят 14 синхронизированных переводов. |
| **Стиль Ряженки** | Компактные строки, единая палитра и оформление на основе `libryazhahand`, рассчитанные на экран консоли. |

## Управление Full-режимом

| Действие | Управление |
|---|---|
| Открыть увеличенную карточку | `A` или касание карточки |
| Закрепить / открепить карточку | `X` |
| Переместить виджет | Перетаскивание одним пальцем |
| Изменить размер | Щипок двумя пальцами |
| Скрыть / показать основную панель | `−` |
| Открыть настройки выбранного режима | `+` |
| Вернуться назад | `B` |

Полное закрытие оверлея убирает и закреплённые карточки. Если виджеты должны продолжать отображаться поверх игры, используйте `−`, чтобы скрыть только панель Full.

## Режимы

| Режим | Назначение |
|---|---|
| **Полный** | Частоты, нагрузки, память, игра, температуры, питание, FPS, разрешение и скорость чтения с SD. |
| **Мини** | Компактная настраиваемая строка показателей для постоянного отображения. |
| **Микро** | Минимальный вариант мониторинга с низким потреблением экранного пространства. |
| **FPS-график** | График FPS с фактической шкалой частоты обновления экрана. |
| **FPS + Гц** | Крупный показатель FPS и текущей частоты экрана. |
| **Разрешение** | Разрешение рендера и viewport запущенной игры. |
| **Прочее** | Отдельные экраны состояния аккумулятора, зарядки и дополнительных системных показателей. |

## Установка

1. Скачайте [`Ryazha-Status-Monitor.zip`](https://github.com/Dimasick-git/Ryazha-Status-Monitor/releases/latest/download/Ryazha-Status-Monitor.zip) из последнего релиза.
2. Распакуйте архив в корень SD-карты с объединением папок.
3. Полностью перезапустите Tesla Menu и выберите **Ряжа-Монитор**.

Архив содержит готовую структуру:

```text
switch/.overlays/Ryazha-Status-Monitor.ovl
config/status-monitor/config.ini
config/status-monitor/lang/*.json
config/ryazhahand/config.ini
```

## Настройки EMA

В разделе **Настройки → EMA-сглаживание** доступны отдельные переключатели для FPS, частот, загрузок, температур и питания. При отключении категории её значения сразу возвращаются к исходным данным датчиков.

## Сборка

Необходимы devkitPro, `libnx` и рекурсивно инициализированные зависимости:

```bash
git clone --recurse-submodules https://github.com/Dimasick-git/Ryazha-Status-Monitor.git
cd Ryazha-Status-Monitor
make -j$(nproc)
make dist
```

После сборки в корне проекта появятся `Ryazha-Status-Monitor.ovl` и готовый установочный архив `Ryazha-Status-Monitor.zip`.
