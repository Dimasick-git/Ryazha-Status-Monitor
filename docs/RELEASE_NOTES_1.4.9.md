# Ryazha Status Monitor 1.4.9

Версия **1.4.9** — патч безопасности и надёжности. Рекомендуется всем пользователям 1.4.8: скачайте полный ZIP, распакуйте его в корень SD-карты и замените предыдущую установку.

## Безопасность и надёжность

| Область | Изменение |
| --- | --- |
| SMD | Добавлены лимиты размера входного файла и памяти форматирования; широкие поля больше не читают данные за пределами временного буфера. |
| Запуск режима | Аргумент `--file` принимает только безопасное относительное имя `.smd` из каталога режимов. Обход каталогов и не-обычные файлы отклоняются. |
| SMSE | Ограничены размеры файлов, буферов, числа расширений, команд, полей структуры и регулярных выражений. Проверяются целостность чтения, числовые значения, имена сервисов и границы каждого поля ответа. |
| CI | Все Actions закреплены по SHA, стандартные задачи имеют только чтение содержимого, а образ devkitPro закреплён по digest. |

## Интерфейс

Подсказки комбинаций теперь используют упорядоченную карту глифов **Switch 2 Style** из libryazhahand. Обновлены символы `Plus`, `Minus`, `LS`, `RS`, а также добавлены `SL` и `SR`. Отображение комбинаций стало стабильным: одинаковый набор кнопок всегда имеет одинаковый порядок.

## Проверки

Выполнены строгие тесты SMD-парсера, AddressSanitizer/UndefinedBehaviorSanitizer, тест роста памяти обычной конфигурации, статический анализ C++, проверка полного набора переводов и отдельные проверки SMSE-парсера. Нативная devkitPro-сборка и упаковка архива выполнены в GitHub Actions.

Подробная модель доверия и практические рекомендации находятся в [docs/SECURITY.md](SECURITY.md).
