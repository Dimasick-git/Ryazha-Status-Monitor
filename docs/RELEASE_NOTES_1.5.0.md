# Ryazha Status Monitor 1.5.0

> **English — short:** This clean 1.5.0 rebuild delivers the complete Switch 2 Style UI through libryazhahand, consistent settings and translations, and Russian as the default language for new installations.

---

Версия **1.5.0** подготовлена как чистая пересборка интерфейса и дистрибутива. Она использует **libryazhahand** как единый источник Switch 2 Style, включает русский язык для новых установок и приводит конфигурацию, меню настроек и локализации к одной схеме.

## Полный Switch 2 Style

| Область | Изменение |
| --- | --- |
| Библиотека | `libryazhahand` экспортирует общий флаг, палитру и размеры Switch 2 Style. Status Monitor фиксирует submodule на этой версии. |
| Фокус и обводка | Все интерактивные пункты списка получают скруглённую трёхслойную рамку Switch 2 вместо квадратной классической подсветки. |
| Переключатели | Тумблеры используют полноценный pill-контрол 48×26 с общей палитрой, резервируют корректную ширину строки и не показывают устаревшие глифы под элементом. |
| Footer-кнопки | Стандартные подсказки `B`, `A`, `Y`, `↑` и `↓` отрисовываются отдельными скруглёнными кнопками с локализованными подписями. |
| Совместимость | При `switch_2_style=false` сохраняется классический вид интерфейса. |

## Настройки и язык

| Область | Значение по умолчанию в чистой установке |
| --- | --- |
| Язык | `override_language=true`, `override_language_ietf_code=RU-RU` |
| Switch 2 Style | `switch_2_style=true` |
| Позиция оверлея | Добавлен локализованный переключатель сохранения и восстановления позиции оверлея. |
| Локализации | EN-US, PL-PL, DE-DE и RU-RU содержат полный одинаковый набор ключей меню. Встроенный fallback также полностью русифицирован. |

## Установка

Скачайте полный ZIP релиза, распакуйте его в корень SD-карты и замените предыдущую установку. Для чистого применения значений по умолчанию удалите старый файл `sdmc:/config/status-monitor/config.ini` перед первым запуском.

Чтобы вернуться к классическому UI, отключите **«Включить стиль Switch 2»** в меню настроек или задайте `switch_2_style=false` в секции `[status-monitor]` файла `sdmc:/config/status-monitor/config.ini`.

## Проверки

Релиз проходит проверку целостности локализационной и конфигурационной schema, host-тесты SMD-парсера, нативную devkitPro-сборку `.ovl`, упаковку полного ZIP и проверку GitHub Actions.
