# Ryazha Status Monitor 1.5.0

> **English — short:** Switch 2 Style is now provided by the current libryazhahand submodule, enabled by default, and can be changed in Status Monitor settings.

---

Версия **1.5.0** переводит интерфейс монитора на актуальную библиотеку **libryazhahand** и включает стиль **Switch 2** по умолчанию. Обновление сохраняет существующие настройки и добавляет штатный переключатель стиля в меню настроек.

## Интерфейс и библиотека

| Область | Изменение |
| --- | --- |
| libryazhahand | Submodule обновлён до актуальной версии библиотеки, используемой проектами Ryazhahand. |
| Switch 2 Style | Стиль включён по умолчанию через `switch_2_style=true` и управляет элементами UI библиотеки. |
| Настройки | В разделе настроек добавлен переключатель **«Включить стиль Switch 2»**. Выбранное значение сохраняется в `sdmc:/config/status-monitor/config.ini`. |
| Сборка | Свежий git checkout и CI автоматически инициализируют submodule из его штатной папки перед компиляцией. |

## Установка

Скачайте полный ZIP релиза, распакуйте его в корень SD-карты и замените файлы предыдущей установки. Для возврата к классическому отображению установите `switch_2_style=false` в секции `[status-monitor]` файла `sdmc:/config/status-monitor/config.ini` или отключите переключатель в меню настроек.

## Проверки

Выполнены тесты SMD-парсера и проверка чистоты diff. Нативная сборка `.ovl` и упаковка дистрибутива выполняются в GitHub Actions.
