# Конфигурация Ryazha-Status-Monitor

Рабочий файл настроек устанавливается вместе с оверлеем по пути `sdmc:/config/status-monitor/config.ini`. Русская локаль находится в `sdmc:/config/status-monitor/lang/ru.json`, а базовые параметры `libryazhahand` — в `sdmc:/config/ryazhahand/config.ini`.

Значения цветов используют формат `RGBA4444`: каждый из четырёх символов описывает канал красного, зелёного, синего и прозрачности.

## Общие параметры

| Ключ | Описание | Значение по умолчанию |
|---|---|---|
| `battery_avg_iir_filter` | Использовать усреднённые показания контроллера аккумулятора. | `false` |
| `battery_time_left_refreshrate` | Интервал пересчёта оставшегося времени аккумулятора в секундах. | `60` |
| `average_gpu_load` | Использовать отдельный усреднённый опрос загрузки ГП. | `false` |
| `use_old_fps_average` | Использовать альтернативное усреднение FPS. | `false` |
| `ema_fps` | EMA-сглаживание FPS. | `false` |
| `ema_frequencies` | EMA-сглаживание целевых и реальных частот ЦП, ГП и ОЗ. | `false` |
| `ema_loads` | EMA-сглаживание загрузок и пропускной способности ОЗ. | `false` |
| `ema_temperatures` | EMA-сглаживание датчиков температуры. | `false` |
| `ema_power` | EMA-сглаживание тока, напряжения и мощности аккумулятора. | `false` |

> EMA влияет только на показания на экране. Частоты, напряжения и другие параметры Nintendo Switch не изменяются.

## Режим «Полный»

| Ключ | Описание | Значение по умолчанию |
|---|---|---|
| `refresh_rate` | Частота обновления оверлея. | `2` |
| `sample_rate` | Частота опроса данных; не выше `refresh_rate`. | `2` |
| `layer_width_align` | Начальная сторона: `left` или `right`. | `left` |
| `use_ryazha_theme` | Использовать активную тему `libryazhahand`. Работает только в «Полном» режиме. | `true` |
| `show_real_freqs` | Показывать реальные частоты при доступном источнике данных. | `true` |
| `show_target_freqs` | Показывать целевые частоты. | `true` |
| `show_deltas` | Показывать разницу целевых и реальных частот. | `true` |
| `show_fps` | Показывать FPS игры. | `true` |
| `show_res` | Показывать разрешение игры. | `true` |
| `show_read_speed` | Показывать скорость чтения игры. | `true` |

## Режим «FPS + Гц»

| Ключ | Описание | Значение по умолчанию |
|---|---|---|
| `refresh_rate` | Частота перерисовки оверлея. | `30` |
| `sample_rate` | Частота опроса FPS; не выше `refresh_rate`. | `30` |
| `integer_fps` | Отображать FPS без дробной части. | `true` |
| `show_refresh_hz` | Показывать фактическую частоту обновления экрана рядом с FPS. | `true` |
| `frame_offset_x` / `frame_offset_y` | Сохранённая позиция перетаскиваемого оверлея. | `0` |
| `touch_move_delay` | Время удержания касания перед перемещением, мс. | `500` |
| `button_move_delay` | Время удержания `+` перед перемещением стиком, мс. | `1000` |

## Компактные режимы

Режимы «Мини», «Микро», «FPS-график» и «Разрешение» имеют собственные цвета и параметры рамки. Их положение сохраняется после перетаскивания. Для изменения параметров выделите режим в главном меню и нажмите `+`.

Встроенное меню предоставляет доступ ко всем поддерживаемым переключателям, цветам, размерам текста, интервалам опроса и перемещению. Редактирование `config.ini` вручную требуется только для резервного копирования или массовой настройки.
