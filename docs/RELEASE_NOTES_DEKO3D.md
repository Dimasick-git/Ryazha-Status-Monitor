# Ryazha-Status-Monitor 1.5.5-deko3d

- Добавлен живой размытый фон через deko3d.
- Поддержан переключатель «Размытие GPU» в настройках оформления Ryzhand 2.5.2.
- Сохранена обычная отрисовка при отключённом размытии или недоступном захвате кадра.

Распакуйте ZIP в корень SD-карты с заменой файлов. Для стекла нужны Ryzhand 2.5.2 и nx-ovlloader 2.0.3-deko3d; после установки загрузчика полностью перезагрузите консоль.

Подложки Full, Mini, Micro, FPS Graph, FPS Counter и Game Resolutions пропускают размытие при готовом кадре. Настроенные цвета сохраняются при обычной отрисовке.
