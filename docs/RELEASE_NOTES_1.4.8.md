# Ryazha Status Monitor 1.4.8

Версия **1.4.8** посвящена стабильности, полноте локализации и чистой повторяемой сборке. Это обновление не меняет формат установки: скачайте полный `Ryazha-Status-Monitor.zip` и распакуйте его в корень SD-карты.

## Исправлено

| Область | Исправление |
| --- | --- |
| Полный режим | Исправлена безопасная отрисовка при любых сочетаниях «Целевые частоты», «Реальные частоты» и «Дельты частот». Отключение отдельных строк больше не оставляет неинициализированные размеры текста. |
| Тесты | Добавлен регрессионный тест всех восьми сочетаний настроек частот Full-режима. |
| Диагностика | Тесты теперь учитывают поддерживаемую команду `RoundedBox`; сборка тестов проходит без предупреждений. |
| Локализация | Добавлены отсутствовавшие польские и немецкие названия и описания настроек во встроенных режимах. Все пользовательские настройки встроенных SMD-режимов имеют переводы для поддерживаемых языков. |
| Скрипты | Обновлены локальные проверка и сборка: они используют актуальный `.ovl`, полный ZIP и реальные файлы конфигурации. |
| Автоматизация | Удалены устаревшие сценарии, которые создавали автоматические коммиты, теги или ошибочные пакеты. |

## Улучшено

Проверки SMD-парсера теперь запускаются со строгими предупреждениями компилятора. Обычный набор тестов дополнительно выполняет проверку роста памяти, а санитайзерный набор остаётся доступен отдельной конфигурацией.

Dockerfile упрощён и использует тот же образ devkitPro, что и CI. Удалены неподдерживаемый `docker-compose.yml` и фиктивная документация о Docker Registry: проект не публикует контейнеры и не требует Docker Hub credentials.

README и руководства были сокращены и упорядочены: сначала приведена короткая английская сводка, затем подробная русская информация. Исправлены неактуальные пути, синтаксис `GET_DIMENSIONS` в примерах и описание `ROUNDED_BOX`.

## Установка

1. Скачайте `Ryazha-Status-Monitor.zip` из этого релиза.
2. Распакуйте архив в корень SD-карты.
3. Убедитесь, что существуют `sdmc:/switch/.overlays/Ryazha-Status-Monitor.ovl` и `sdmc:/config/status-monitor/`.
4. Откройте оверлей через Ryazhahand, Ultrahand или Tesla Menu.

> Не устанавливайте только `.ovl`: встроенные режимы, расширения и локализация находятся в папке `config/status-monitor`.

## Проверка релиза

Перед публикацией выполнены тесты SMD-парсера в строгом режиме, проверка роста памяти и регрессионные сценарии Full-режима. Полный ZIP проверяется на наличие оверлея и `locale.ini`.
